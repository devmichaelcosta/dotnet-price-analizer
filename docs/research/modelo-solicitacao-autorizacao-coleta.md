# Modelo de solicitação de autorização para coleta de preços

**Estado:** arquivado em 12/10/2026 por decisão do usuário. Não usar nem enviar.

O projeto não contatará lojas por mensagens, formulários, chamados ou pedidos de autorização. A coleta só poderá ser habilitada quando os termos públicos aplicáveis permitirem expressamente a consulta automatizada de páginas HTML públicas. Termos silenciosos ou ambíguos deixam o domínio desabilitado.

Este arquivo é mantido apenas como registro de planejamento anterior. Não constitui uma ação pendente nem autorização para contatar qualquer loja.
