# Configurar credenciais de fonte — fora do escopo vigente

**Estado:** Fora do escopo vigente — 2026-10-12<br>
**Módulo:** Operations

O MVP manual não usa credenciais de lojas ou fontes externas. A diretriz atual permite considerar somente HTML público futuro; se um domínio exigir autenticação para acessar páginas, ele não atende ao escopo público aprovado e deve permanecer desabilitado.

Este caso de uso não integra o inventário do MVP nem autoriza implementação. Só poderá ser reaberto após mudança explícita de requisito que permita uma fonte autenticada e após revisão do ADR de fontes, segurança, armazenamento e privacidade. As antigas propostas de AC desta spec foram substituídas e não devem orientar código ou testes.
